# Happy Birthday Prithiee 

Attractive interactive birthday wish UI with a real letter-style modal, confetti, and direct Instagram + Snapchat follow links.

## Live Demo

After enabling GitHub Pages (Settings → Pages → Source: Deploy from a branch → main / root), the site will be available at:

**https://askrishnaprasath-png.github.io/birthday-wish-prithiee/**

## Features

- Soft pink gradient background with floating bubbles
- Glassmorphism landing card
- "Birthday Treat Application Letter" button that opens a paper-like letter modal
- Confetti celebration on letter open
- Instagram & Snapchat buttons with Font Awesome icons (linked to your profiles)
- Fully responsive

## How to enable GitHub Pages (one-time)

1. Go to the repository: https://github.com/askrishnaprasath-png/birthday-wish-prithiee
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Build and deployment** → Source: select **Deploy from a branch**
4. Branch: **main** + **/ (root)** → Save
5. Wait 1–2 minutes, then open the live URL above.
